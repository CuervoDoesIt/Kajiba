<objective>
Create `experiment_drift.py`: a new Click-free, stdlib-only pure-compute module
holding the drift algorithm (EREV-03 / D-12..D-15). `compute_drift(records,
threshold=DRIFT_THRESHOLD) -> dict[str, bool]` groups runs by
`(local_model.model_name, task_category)`, compares each run's `eval_score` to the
leave-one-out mean of the OTHER runs in its group, and flags BOTH directions
beyond the threshold. Groups with `<2` runs are never flagged. The verdict spans
every input record so the `drift` CLI command (13-05) can SET and CLEAR
`drift_flag` idempotently.

Purpose: Isolate the only genuinely new algorithm in this phase as a pure,
unit-testable function — mirroring `eval_scorer.py`'s compute-module shape — but
with the OPPOSITE persistence story: eval score is compute-on-read, drift is
computed then PERSISTED by the caller (D-02).
Output: `src/kajiba/experiment_drift.py` with `DRIFT_THRESHOLD = 0.15` and
`compute_drift`. Turns the 13-01 `tests/test_experiment_drift.py` RED tests
GREEN. No schema change.
</objective>
