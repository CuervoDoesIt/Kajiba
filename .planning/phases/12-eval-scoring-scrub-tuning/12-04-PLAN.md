<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user CLI arg (record_id) → store path | Untrusted `<id>` string used to construct a filesystem path — must be constrained to EXPERIMENTS_DIR |
| `--from`/store JSON → load_record | Untrusted record JSON validated by Pydantic; non-experiment records rejected before processing |
| scrubbed output → stdout / --out file | Scrub fires at the share boundary; the raw store file must never be overwritten (D-08) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-10 | Tampering (path traversal) | _load_experiment(record_id) | mitigate | Construct `EXPERIMENTS_DIR / f"exp_{record_id}.json"` and verify `path.resolve().parent == EXPERIMENTS_DIR.resolve()` before read (mirror Phase 11 D-13 guard); reject otherwise with ClickException |
| T-12-11 | Tampering / DoS (malformed record) | experiment score/scrub on bad JSON | mitigate | `load_record` + Pydantic ValidationError + `isinstance(rec, ExperimentRecord)` guard before processing; clean ClickException, no traceback (test_experiment_score_missing) |
| T-12-12 | Information Disclosure (raw PII at rest overwrite) | experiment scrub --out / preview | mitigate | scrub NEVER overwrites the raw `exp_<id>.json`; preview to stdout or explicit `--out`; test asserts on-disk bytes unchanged (D-08, closes AR-11-01 at share boundary not at rest) |
| T-12-13 | Information Disclosure (confidence/score confusion) | experiment list / score render | mitigate | New column labelled "Confidence" (NOT "Score"); eval_score rendered separately (Pitfall 4) so eval trust ≠ answer quality ≠ training tier |
| T-12-SC | Tampering | npm/pip/cargo installs | accept | Phase installs ZERO packages (RESEARCH Package Legitimacy Audit: not applicable) |
</threat_model>
